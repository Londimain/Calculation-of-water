Расчёт показаний счётчиков воды

Веб-приложение для прогнозирования показаний счётчиков воды на основе данных за предыдущие периоды.

📋 О программе

Приложение предназначено для расчёта прогнозных показаний счётчиков воды Ду-20 и Ду-80 на основе фактических данных основного счётчика и дополнительных счётчиков за три месяца.

Программа использует метод экстраполяции на основе коэффициентов расхода, позволяя с высокой точностью предсказать показания на следующий период.

✨ Возможности программы

    🔢 Ввод данных за три месяца для основного счётчика и дополнительных (Ду-20, Ду-80)

    📊 Автоматический расчёт прогнозных показаний на основе коэффициентов расхода

    📈 Корректировка прогноза с учётом статистических отклонений

    🔄 Перенос данных для расчёта следующего периода

    🧹 Очистка всех полей одним кликом

    📱 Адаптивный дизайн для работы на любых устройствах

    🎨 Современный интерфейс с анимацией и эффектами

🧮 Алгоритм расчёта

    Расчёт расхода основного счётчика между 1‑м и 2‑м месяцем

    Расчёт расхода Ду‑20 и Ду‑80 между 1‑м и 2‑м месяцем

    Вычисление коэффициентов доли расхода для каждого счётчика

    Расчёт расхода основного счётчика между 2‑м и 3‑м месяцем

    Прогнозирование расхода Ду‑20 и Ду‑80 на 3‑й месяц

    Корректировка прогноза с учётом статистических данных

        Ду-80: -100 единиц

        Ду-20: +5 единиц

📖 Руководство пользователя

1. Ввод данных

    В поле «Основной счётчик: 1 месяц» введите показания за первый месяц

    В поле «Основной счётчик: 2 месяц» введите показания за второй месяц

    В поле «Основной счётчик: 3 месяц» введите показания за третий месяц

    Аналогично заполните поля для Ду‑20 и Ду‑80

2. Расчёт

Нажмите кнопку «Рассчитать» для получения прогнозных показаний на 3‑й месяц.

3. Результаты

Результаты отображаются в блоке «Результаты расчёта»:

    Ду‑20: прогнозное показание на 3‑й месяц

    Ду‑80: прогнозное показание на 3‑й месяц

4. Перенос данных на следующий месяц

Нажмите кнопку «Следующий месяц» для автоматического переноса данных:

    Данные 2‑го месяца → в 1‑й месяц

    Данные 3‑го месяца → во 2‑й месяц

    Результаты расчёта → в поля Ду‑20 и Ду‑80 за 2‑й месяц

    Поле 3‑го месяца очищается для ввода новых данных

5. Очистка всех полей

Нажмите кнопку «Очистить всё» (если она добавлена) для полной очистки всех полей ввода.

🐛 Известные проблемы и их решение

Проблема	Решение
Не отображаются фавиконы	Проверьте наличие папки images/png с файлами
Кнопки не работают	Проверьте, что файл script.js подключён и находится в той же папке
Неправильный расчёт	Убедитесь, что все поля заполнены корректными числами
Ошибка при переносе данных	Убедитесь, что все поля заполнены, включая результаты расчёта

🔧 Настройка коэффициентов

В файле script.js можно изменить коэффициенты корректировки:

// Финальная корректировка для Ду‑20 и Ду-80
const finalDu80 = predictedDu80 - 100; // Коэффициент для Ду-80
const finalDu20 = predictedDu20 + 5;   // Коэффициент для Ду-20

Изменяйте значения 100 и 5 в соответствии с вашими статистическими данными.
